# ryP0 Repository Data

This public repository contains only the ryP0 package manifest and public icon
assets. It intentionally contains no application source code, automation, or
credentials.

Package managers and read-only clients can use:

`https://raw.githubusercontent.com/Sami-Wali/ryP0-repository/main/repo.json`

Release binaries are published separately in
[`Sami-Wali/ryP0`](https://github.com/Sami-Wali/ryP0/releases).
